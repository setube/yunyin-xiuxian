# 转生不限次重刷灵根

用户已确认：每次转生与首次建角一样，可不限次重刷灵根，满意后再确认。

- 在既有转生第二程展示来世灵根：品阶、元素、资质、修行倍率与「逆天改命」按钮。
- 草稿留在临时转生视图中；重刷只换灵根，不重抽天赋、不发放奖励、不改变本世角色。
- 确认使用最后一次展示的灵根，不再随机生成另一份。转生次数、宿慧、道果及传承照原流程结算。
- 保留原有转生资质加成：以本次结算后的宿慧及原有次数公式生成草稿。
- 沿用转生窗口现有刷新语义：刷新后重新准备，不新增存档字段。

方案取舍：复用首次建角页面会触发建号初始化与新手奖励，并受已有存档路由守卫阻挡；直接在转生窗口加入草稿和重刷最小且符合现有流程。转生后随时改灵根超出需求。

验证：真实服务测试证明预览不落账、重刷不限次、资质加成及所见即所得；全量测试、类型与 lint、生产构建，以及浏览器点击转生与重刷。
