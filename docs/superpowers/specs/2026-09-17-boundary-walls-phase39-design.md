**关联反馈**:

## 一 两段谶:改动前后的世界

这两段不是装饰,是这一版的手感描述 —— 前一段是**改动前**(道在眼前),后一段是**改动后**(壁起渊围)。

### 昔 · 改动前

> 昔者鸿蒙未判,混沌初开,天枢未收,界膜未凝。大道不隐,直接显于万象;玄机不藏,直接流于微尘。日月是经,山河是诀;风雷为鼓,呼吸为门。
>
> 当是时也,无壁可破,无劫可渡。一念合真,便越三界;半步相应,即登诸天。晋升如露上青叶,飞升如月出浮云。凡圣同途,人天共路;未设天关,未铸铁锁。道在眼前,不假苦修;法在当下,不待劫数。
>
> 所以彼时晋升,不曰突破,曰归真;不曰逆天,曰合道。无门而处处是门,无梯而步步登天。
>
> 故有谶曰:
>
> 鸿蒙未锁,大道亲垂。
> 一念登真,举步越界。
> 天机裸呈,玄根遍地。
> 今非昔比,壁起渊围。
>
> 后之来者,当知:昔者道在眼前,今者道隔重渊;昔者门开如掌,今者壁立如天。

数值上「道在眼前」= 三件事同时成立:修为丹按**当前一层需求的百分比**结算(囤低阶丹到高境界服,等于按比例削掉任意一道墙)、跨界那一境**没有任何额外加难**、渡劫的三维折算(防御→抗性、气血→开劫水位)**给得极厚**。于是从金丹到大罗是同一种手感。

### 今 · 改动后

> 大道有司,默运天枢。诸天界膜,本若薄雾,今则被以因果之锁,铸以规则之铜,镇以无名之印。三千世界之壁,日凝夜厚;界海飞升之门,渐隐渐沉。
>
> 自此而后,凡欲破壁而出、逆升上境者,皆如以萤火撼星河,以一念逆洪流。劫门未封,而天梯已断;机缘未绝,而难数倍增。破界之路,愈行愈艰,愈上愈孤。
>
> 后之来者,当知:壁已非壁,天已非天。

数值上「壁起渊围」= 界末圆满那道修为墙、界膜那一劫不认三维折算、丹药药力改成写死的闭关时长。下表逐句对上。

| 谶中语 | 数值落点 |
|---|---|
| 三千世界之壁,日凝夜厚 | 每大境界净耗时抬一档(见「四 数值」) |
| 界海飞升之门,渐隐渐沉 | 界末圆满加一道修为墙(`WORLD_STEP_EXP_MULT`) |
| 劫门未封,而天梯已断 | 跨界那一劫仍要渡,但它不再认血肉之厚(`TRIB_WORLD_STEP_STAT_FOLD`) |
| 机缘未绝,而难数倍增 | 机缘/奇缘/际遇三档仍在,但丹药与境界不再白送进度(见「五 丹药」) |

## 二 状态面板不再抖(界面)

### 根因

状态胶囊是 `white-space: nowrap` 的,而倒计时用的 `formatDuration` **宽度会随时间变**:

```
9分59秒(6 字) → 10分0秒(6 字) → 10分1秒(6 字) → 10分10秒(7 字)
```

宽度一涨一缩,同一行里后面的胶囊整排跟着左右跳 —— 玩家看到的就是「状态信息一直在抖」。

### 做法

- 新增 `formatCountdown`(`src/utils/format.ts`):分钟与秒逐位补零,**同一量级内每一秒的文本宽度完全相同**(逐位替换,不换行不回流)。
- 状态胶囊、闭关倒计时、调息倒计时、状态详情弹窗一律改用它,并给倒数留一个固定宽度右对齐的槽位(`min-w-[3.5rem]`)+ `tabular-nums`。
- 判据:`src/utils/format.spec.ts` 按**宽度**断言,不按字符串花样 —— 分秒量级内逐秒走一遍,宽度只允许有一种。

## 三 历练三档触发:际遇 / 机缘 / 奇缘

### 病灶

三档从前共用「际遇」一个标题、同一种版式、也从不告诉玩家概率。于是一枚**千分之几**的机缘与一件路边小事在体感上完全一样 —— 稀有度白设了。

### 做法

口径只此一处:`src/core/eventTier.ts`。档名、颜色、一句话、稀度全从这里取;
概率按**引擎真实的闸门顺序**算(出事 → 先掷奇缘、再掷机缘、余下才是际遇),
数字落在 `src/data/constants.ts`。

| 档位 | 来历 | 每程约 |
|---|---|---|
| 际遇 | 出事后取寻常池 | 缘未起 ≈每 6.4 程 · 缘在续 ≈每 9.1 程 |
| 奇缘 | 出事后取「你这条缘该走的下一程」(闸门 0.3) | **只在缘在续时** ≈每 20.8 程 |
| 机缘 | 没走奇缘才极小概率撞上(0.02) | 缘未起 ≈每 319 程 · 缘在续 ≈每 446 程 |

两个缘分状态都要报:第一版把三档当成「出事」池里的互斥抽取,公告「际遇每 6 程 ·
奇缘每 21 程 · 机缘每 313 程」——**三者之和 0.211 大于「出事」本身的 0.16,数学上就
不可能同时成立**,而玩家读到的稀度正是这一版的卖点。现在界面按玩家**此刻有没有缘在续**
显示,判据用真引擎做两万次蒙特卡洛对账(`eventTier.spec`),模型与引擎不许分叉。

- 弹窗:档位横幅(名字 + 这一档是什么 + 多久撞一次),标题仍是事件自己的名字。
- 历练页:出发之前就把三档与稀度摆出来(`EVENT_TIERS`),不必等撞上才知道有档位这回事。
- 触发瞬间:机缘 / 奇缘各有自己的提示语,不再静悄悄地以一个「际遇」弹窗出现。
- 判据:`src/core/eventTier.spec.ts`(分类互斥、稀度梯级不许倒挂、界面读同一份口径)。

## 四 渡劫加难

### 一个必须先说清的约束

天劫伤害口径在 `TRIBULATION_DIFFICULTY_CAP_MAJOR = 9` 处封顶,而 `tribulationSpace.spec.ts` 有两道硬门:

- 四维皆优的参考构筑,在每个需渡劫的境界都能渡任一劫型;
- 每个需渡劫的境界 × 每种劫型,都还剩**至少一条非满配之路**。

实测:**伤害再加 4% 就会让参考构筑在雷鸣 / 逆流劫下落败**。也就是说,单纯抬伤害这条路上限只有 3%。

### 于是走三条都不碰解题空间的路

1. **伤害 +3%**:`0.15/0.02/0.03` → `0.155/0.02/0.031`(系数收进 `TRIB_WAVE_*`)。
2. **三维折算收窄**:防御→抗性上限 30% → 18%、气血→开劫水位上限 60% → 35%、每倍折算 5% → 4%。上一版这两条兜底给得太厚 —— 厚到把渡劫的四维解法空间挤掉一半,这正是「渡劫又太容易」的主要来源。
3. **界膜那一劫不认三维折算**(`TRIB_WORLD_STEP_STAT_FOLD = 0`):只加三个跨界入口(9 / 14 / 18),界内的关照旧。加在**规则**上而不是公式上,是因为参考构筑只带词条、从不吃三维折算 —— 公式一抬会同时挤掉解题空间,而这条只收回玩家的白拿部分,三条非满配之路一条不少。

### 玩家必须提前知道

界膜之劫的规则写在劫势面板上(突按钮之前):「血肉之厚一概不算 —— 防御与气血折算出的抗性、开劫护持在此作废,只认词条与准备」。上一版玩家吃过「护持明明写着有、过劫时却像没有」的亏,这种误会不该靠一次失败去发现。

## 五 丹药不再按百分比结算

### 病灶(旧口径的账)

修为丹的药力是「**当前一层需求的百分比**」(7%~62%)。这看着自平衡,实则把指数增长的需求墙整段搬给了玩家:

- 需求每境 ×19(界外 ×4.6),成本却冻结在丹方自己的准入境界;
- 于是同一枚金丹期的丹留到混沌海服用,药力跟着需求涨到万亿倍;
- 结果:囤低阶丹、到高境界嗑,成为破界的最优解 —— 上一条加难出来的墙,全被这一条买通。

`core/pillValue.ts` 的「未处置的账」里早就记着这笔(可炼修为丹的性价比跨百万倍)。

### 新口径

修为丹改按**等效闭关时长**(`expSecs`)结算:

```
修为增加 = 服丹者当下的修炼速度 × expSecs,封顶在「不满一层」(INSTANT_EXP_LAYER_CAP)
```

- 药力在**任何境界都是同一段时长**,囤到高境界只会显得它更弱(这是对的)。
- 封顶守的是低境界那一段:炼气一层只要几十秒,不封顶的话一枚写在纸上的「闭关三时」能连跳好几层。
- 十二味修为丹的阶梯改写成「服之如闭关 X」——具体档位见第七节:**本节定的第一版阶梯
  (30 分~2 日半)在第七节被按历练基准重定为「一刻~六时」**,以那一节为准。
- 灵气丹保留百分比:容量与回速同阶,折成时间本就近乎恒定(满额回满必须可炼,见丹药定价法则 F);限时的修速 / 战斗增益丹也不动 —— 它们有到期时间,吃不到复利。
- 判据:`core/pillValue.spec.ts` 法则 G(药力不随境界膨胀、单枚永不满一层、旧字段不许回来)、`core/pillService.spec.ts` 的结算端到端。

## 七 续:同一条病的另一处 —— 历练的修为也是百分比缩放

丹药改完之后顺手把「按当前需求百分比结算」这件事全库查了一遍(`rg expReq`),四处里有三处仍是旧口径:

| 处 | 口径 | 结果 |
|---|---|---|
| 丹药 `pillService` | ~~当前一层需求的 7%~62%~~ | Phase 39 已改为等效闭关时长 + 封顶 |
| 战斗 `loot.afterWin` | 当前一层需求的 **1.2%** | 本节处理 |
| 离线历练 `offline` | 同上 ×胜场 | 同上(与在线同源) |
| 际遇/机缘 `eventEngine` | 当前一层需求的 **5%~15%** | 同上 |

为什么这一处比丹药严重得多:**遭遇是自动进行的** —— 在线每 12 秒一场,离线照算,每小时 252 场。而一层耗时每境 ×3.65,于是"一场遭遇"折算出的闭关时间随境界指数上涨。实测读数(核心 `core/expIncome`,`bunx vitest run src/core/expIncome.spec.ts`):

| 境界 | 每场遭遇 ≈ 多少闭关 | 历练 ÷ 挂机 |
|---|---|---|
| 炼气 | 1.1 秒 | ×0.08 |
| 金丹 | 14.8 秒 | ×1.0 |
| 元婴 | 53.9 秒 | ×3.8 |
| 化神 | 3.3 分 | ×14 |
| 合体 | 43.9 分 | ×184 |
| 渡劫 | 9.8 时 | ×2459 |
| 真仙 | 35.7 时 | ×8984 |
| 混沌道祖 | 1931 时 | ×486603 |

也就是说:自金丹起历练的修为收入就超过挂机修炼,合体起超十倍,真仙起超九千倍 —— 「修为/秒、闭关 +150%、修炼速度词条」在化神之后近乎装饰,而本仓库所有"这一境要修多久"的读数(progressionSim / realPacing / 本文档第六节)**只算了挂机那一条线**。上一节那道界末圆满的墙(≈2 层)在真仙只需约 83 场遭遇(≈20 分钟)就能跨过去。

### 设计裁决:修为只有一种计价单位

先加了一层「等效闭关封顶」把跑飞的部分按住(每场至多一个时辰),但那只把比值从真仙 8984× 收到 252× —— **挂机修炼在深境依旧不是一条路**。按"这游戏该怎么设计"重新拍板,口径改成一句话:

> **一切即时修为 = 修速 × 一段等效闭关时长,且不满一层。**

三条渠道因此各有其位,而且**三个倍率在任何境界都相同**(因为都只跟"修速"走)。
注意「历练」是与挂机**并行**的(遭遇是自动的),所以要比的是**合计**:

| 渠道 | 倍率 | 代价 / 所得 |
|---|---|---|
| 挂机修炼 | **1.0×** | 什么也不用做 —— 这是底 |
| 历练那一半(与挂机并行) | **+≈1.5×** | 另给灵石/材料/装备/丹药;一场遭遇 12 秒等效、一次际遇 30~120 秒 |
| 挂机 + 历练 合计 | **≈2.5×** | 出门就是这条路 |
| 闭关 | **≈2.5×** | 期间**不能历练** —— 放弃掉落换专注 |

**三者恰好闭合:闭关与「挂机 + 历练」打平**(9000 vs 9050 等效秒/小时,差 0.6%)——
于是「专心修炼」换来的是不被打断、代价是放弃掉落;「出门历练」换来的是掉落、
代价是修为上并不更快。没有哪条路白送,也没有哪条路是死路。

实施要点:

- 一场遭遇 `BATTLE_EXP_SECS = 12` 秒、一次际遇见 `data/events` 与 `data/chains` 的 `secs`(30~120 秒)——**`reqPct` 这个字段整体删掉了**,事件数据从"需求的百分比"改写成"多少秒闭关"。
- 四条来源(丹药 / 一场遭遇 / 离线 N 场 / 际遇)共用 `formulas.expFromSecs`;离线把秒数与层上限一并乘胜场数,「N 场」恒等于「N 次单场」。
- 封顶只认「不满一层」(`INSTANT_EXP_LAYER_CAP = 0.9`):与境界无关的自然刻度,守的是低境界那一段(炼气一层只要 92 秒,而首领 ×4、涉险 ×1.9、福缘 ×2 能把裸账叠到 3 层)。
- 于是**修速词条、洞府、灵脉、闭关、丹药增益对两条收入线同时有效** —— 这正是修好之后的性质,也是修之前丢掉的性质。

读数的意义也随之变了:它不再是"抱怨某个数太大",而是**设计不变量**。`core/expIncome.spec` 现在守的是场景:

① 21 境里「挂机+历练」与「闭关」都 ≈2.5× 挂机、彼此相差 <5%(三角闭合);② 界末圆满那道墙(×2)单靠胜场也要十天以上(实测渡劫圆满 ≈ 95 天、大罗圆满以年计);③ 炼气期叠满首领+涉险+福缘也只给「不满一层」;④ 离线 N 场 = N 次单场;⑤ 同一段时长在深境只更不值钱,修速翻倍则收益翻倍;⑥ 每条际遇/机缘的修为都在 30~120 秒;⑦ 四条来源不许绕开 `expFromSecs` 自己再算百分比、经济审计不许再推一遍速率(读源码的红线)。

顺带一提:上一节那道界末墙在真仙原本约 83 场遭遇(20 分钟)就能跨过,现在是 **≈41 天**(挂机+历练并行),而纯挂机是 124 天 —— "艰难的一步"这才真的落到了玩家身上。

### 连带:丹药阶梯按同一单位重定价

基准一变,原来的丹药阶梯就露馅了:顶级丹 2 日半的时长,在 12 秒/场的新单位里等于 **18000 场遭遇(71 小时历练)**,而它的 490 味灵草只值约 1.6 小时的战斗 —— 丹药会立刻变成比历练强几十倍的通路。故按一条明文规则重定价:

> **一枚修为丹的时长 ≈ 其灵草成本折算的场次 × 3**(技艺、灵石与炸炉风险的溢价)
